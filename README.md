# House Price Prediction Using Linear Regression

## Project Overview
This project uses Machine Learning to predict house prices using the Boston Housing Dataset and Linear Regression.

## Objectives
- Load and understand the Boston Housing Dataset.
- Perform data preprocessing.
- Handle missing values.
- Apply feature scaling.
- Train a Linear Regression model.
- Predict house prices.
- Evaluate model performance using RMSE and R² Score.
- Save the trained model using Joblib.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Jupyter Notebook

## Machine Learning Algorithm
Linear Regression

## Model Evaluation
The model is evaluated using:
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Files
- `House_Price_Prediction.ipynb` – Complete implementation of the project.
- `README.md` – Project documentation.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.

4. Run all cells sequentially.
